# MatlabAlgoimWrapper

This code provides a Matlab wrapper to the algoim (https://algoim.github.io/) library. 
In particular, the quadrature algorithms for domains implicitly-defined by multivariate polynomials are accessed.  

Interface type: implicit
Operating System: Linux

## Installation
Prerequisites:
* liblapacke (install also the ``dev`` packages of it)

Command to check that the library is installed:
``ldconfig -p | grep liblapacke.so.3``
